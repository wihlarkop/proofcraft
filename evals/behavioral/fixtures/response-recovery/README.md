# Consumer recovery contract

The selected HTTP/JSON API uses stable `code` and optional envelope fields. If body `status_code` is present, it equals the actual HTTP status. Public messages are localized and are not identities.

Operations keep an original operation key and may retrieve an authoritative receipt. The client must not discard a pending mutation until that operation is resolved. The UI has an editable draft and separate background reference-data refresh; failed refresh need not invalidate the editor.
