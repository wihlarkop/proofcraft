# Proofcraft v0.1.0

Proofcraft v0.1.0 is the first public release of the low-ceremony, evidence-driven Agent Skills suite for software engineering across coding agents.

## Highlights

- 23 distributable skills: 10 core workflows and 13 domain engineering skills.
- Adaptive lifecycle covering setup, shaping, architecture, planning, implementation, debugging, acceptance, review, finish, and continuation.
- Provider-neutral composition: project technology and accepted architecture come before optional providers.
- Project-local context and decision-lock rules to reduce stale-memory and invented-policy failures.
- Implementation-first workflow with verification required and TDD optional.
- Canonical artifact ownership for product, architecture, plans, acceptance evidence, handoffs, and project orientation.
- Generated self-contained skill distribution with source/generated parity validation.

## Dogfood evidence

All 10 core workflows were materially exercised through the Mame dogfood cycle.

Representative domain dogfood also covers:

- mobile engineering around local-first/offline and runtime-evidence boundaries;
- database engineering against a real SQLite repository;
- migration engineering through schema-evolution planning and review;
- security engineering for trust boundaries, authorization, secrets exclusion, and untrusted input;
- privacy engineering for purpose, minimization, lifecycle-policy gates, and separation from security mechanisms.

See `docs/dogfood/` for the evidence records and limitations.

## Known coverage limits

Not every domain skill has material runtime dogfood in v0.1.0. UI, API design, external integration, platform, reliability, performance, and AI engineering remain primarily contract/eval-fixture validated. Async-work has partial shaping exposure, and mobile runtime/device coverage remains incomplete.

The JSON eval files are authored behavioral fixtures; CI validates their structure and distribution but does not execute model-scored behavioral evals.

## Install

```bash
npx skills add wihlarkop/proofcraft
```

Update later with:

```bash
npx skills update
```

## Validation

The release candidate is validated by the repository build pipeline:

- rebuild distributable skills;
- validate all 23 generated skills and canonical sources;
- verify generated-tree freshness;
- require no uncommitted generated diff.
