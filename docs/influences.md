# Influences and Provenance

This project is an original synthesis. It does not vendor third-party skill text by default.

Important influences during design include:

- Matt Pocock's skills work — composability, progressive disclosure, grilling, wayfinding, concise agent instructions.
- obra/superpowers — implementation-plan detail and systematic engineering discipline; mandatory TDD/process gates were intentionally not adopted as defaults.
- magnus919/agent-skills — broad domain methodology including verification, migration, API evolution, reliability, privacy, production readiness, and QA.
- Addy Osmani's agent skills — lightweight lifecycle, performance, observability, dependency, migration, and shipping patterns.
- Impeccable — optional UI/design specialist-provider model.
- Agent Skills ecosystem conventions — `SKILL.md`, references, assets, scripts, and progressive disclosure.

Before directly copying or vendoring any third-party material, verify its current license and attribution requirements. Prefer independent adaptation of general engineering principles.
