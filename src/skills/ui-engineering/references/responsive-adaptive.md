# Responsive and Adaptive UI

Responsive UI scales fluidly with available space; adaptive UI may intentionally switch composition or interaction patterns at meaningful constraints.

Prefer content- and behavior-driven breakpoints over device-brand breakpoints. Verify:
- minimum supported viewport/window;
- common intermediate sizes;
- large layouts;
- text scaling/zoom where relevant;
- overflow and long content;
- input modality changes;
- orientation or window resizing when the platform supports it.

Do not treat “mobile responsive” as shrinking desktop UI until it fits.
