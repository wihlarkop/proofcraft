# Reality Check

Before consequential work, reconstruct the state that actually exists.

Inspect only relevant sources, typically:

- current branch, HEAD, base and working tree;
- code paths named by the task;
- current spec/plan/ADR and project context;
- manifests and migrations where relevant;
- CI/PR status when accessible and material.

Classify contradictions explicitly. Prefer current code/runtime/git evidence over stale plans or conversational assumptions. Preserve unrelated changes. Do not ask the human to relay facts that the available environment can directly reveal.
