# Privacy Data Lifecycle

Trace data through:
collection -> processing -> storage -> access/share -> derivation/export -> archival -> deletion.

Include non-obvious copies when relevant:
- replicas;
- caches;
- backups;
- logs/traces;
- analytics exports;
- search/vector indexes;
- model/evaluation datasets;
- support/debug artifacts.

A lifecycle that ends at the primary database is incomplete.
