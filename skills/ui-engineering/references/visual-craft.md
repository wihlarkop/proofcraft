# Visual Craft

Start from product purpose, audience, information hierarchy, and existing design language.

Use intentional choices for:
- hierarchy and grouping;
- typography scale and rhythm;
- semantic color;
- density and whitespace;
- component shape;
- imagery/iconography;
- motion;
- copy.

Avoid generic “AI dashboard” defaults, excessive gradients/glow, decorative motion, and visual novelty that weakens information clarity. Prefer coherent restraint over adding more styling.
