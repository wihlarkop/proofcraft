# Interaction and Accessibility

Design interactions around user intent and available input methods.

Check relevant concerns:
- semantic structure and accessible names;
- focus order and visible focus;
- keyboard operation;
- pointer/hover behavior without hover-only critical actions;
- touch target size and gesture alternatives;
- contrast and non-color cues;
- text scaling and readable hierarchy;
- reduced motion;
- actionable validation/error states;
- loading, empty, disabled, and failure states.

Accessibility is a behavioral constraint, not a final cosmetic audit.
