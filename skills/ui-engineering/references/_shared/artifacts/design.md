# DESIGN.md Contract

`DESIGN.md` owns durable visual and interaction truth for a product.

Useful content includes:
- visual direction and density;
- typography hierarchy;
- semantic color usage;
- spacing/layout principles;
- motion principles;
- interaction vocabulary;
- keyboard, pointer, touch, and focus expectations;
- responsive/adaptive behavior;
- accessibility conventions;
- surface-specific rules for web, desktop, mobile, or hybrid UI.

Do not record transient pixel tweaks or one-off implementation details unless they establish a reusable design rule. Project design truth overrides generic provider recommendations.
