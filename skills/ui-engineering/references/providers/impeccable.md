# Optional Provider: Impeccable

Use Impeccable only when it is installed/available and the current project benefits from its specialist visual-design capability.

Suggested concern mapping:
- typography -> typeset;
- color -> colorize;
- layout -> layout;
- motion -> animate;
- UX copy -> clarify;
- hardening -> harden;
- critique -> critique.

Do not auto-install it. Do not let provider output override PRODUCT.md, DESIGN.md, accessibility constraints, or accepted project decisions. If unavailable, use Proofcraft's built-in UI references.
