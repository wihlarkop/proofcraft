# Evidence Method

For every completion claim:

1. State the criterion.
2. Ask what evidence could falsify the claim.
3. Collect the strongest direct, reproducible evidence available.
4. Render PASS, FAIL, BLOCKED, or N/A/NOT RUN as appropriate.
5. Distinguish verified facts from assumptions and remaining gaps.

If the source is accessible to the agent, the agent owns evidence collection. Missing evidence is never PASS.
