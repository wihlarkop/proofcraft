# Mobile Adaptive Layout and Input

Coordinate with ui-engineering for visual design, while mobile-engineering owns platform behavior.

Check relevant constraints:
- safe areas and system UI insets;
- software keyboard/IME resize and focus behavior;
- touch targets and gestures;
- hardware keyboard where supported;
- system back/navigation;
- orientation/window-size changes;
- text scaling;
- accessibility services;
- platform-specific control expectations.

Do not assume a phone-sized layout represents tablets, foldables, desktop-mode windows, or landscape behavior.
