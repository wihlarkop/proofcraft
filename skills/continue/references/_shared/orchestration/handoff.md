# Handoff

A handoff is a factual checkpoint, not a narrative summary.

Record when useful:

- branch, HEAD and base;
- PR or review reference;
- working-tree state;
- completed behavior;
- exact verification evidence;
- known failures or gaps;
- intentional uncommitted changes;
- next eligible task;
- relevant canonical artifacts.

A future `continue` must still reality-check the handoff because it can become stale.
